# Authors and Contributors

The Digital Voice Modem Desktop Dispatch Console is developed by the
DVMProject community ("DVMProject Authors").

DVMConsole originated from Caleb's (K4PHP) WhackerLink Console and has since
been developed further by DVMProject.

This file is based on the repository's Git history, including its earlier
WhackerLink Console history, supplemented by source notices and recorded
code origins. A name here does not replace or alter the copyright notice or
license in an individual file. Contributor names and handles are consolidated
where the history identifies the same person.

YamlDotNet, and the separately supplied libvocoder runtime. These components
retain their own authorship, copyright, and license notices. This summary is
not a substitute for the notices supplied with those components.
